# Checklist de Deploiement Client (Next.js Static + Cloudflare Pages)

Ce guide recapitule toutes les etapes necessaires pour configurer et deployer un nouveau client a partir de ce template.

---

## 1. Initialisation du projet client
- [ ] Cliquer sur **Use this template** sur GitHub pour creer le depot du client (ex: nom-agence-site).
- [ ] Cloner le projet en local dans WSL : git clone url-du-repo.
- [ ] Installer les dependances : npm install (ou npm ci).

---

## 2. Configuration Metier (src/data/config.ts)

### A. Statut Aeroport & Localisation
- [ ] CITY_HAS_AIRPORT : true uniquement si la ville possede son propre aeroport. Si false (ex: Jadida, Meknes), aucun texte ne dit « Aeroport {ville} » (badge, titre, SEO, pied de page, URL).
- [ ] AIRPORT_SERVICE : true si l'agence propose la livraison / un rendez-vous a l'aeroport.
- [ ] seo.city et seo.cityAr : nom de la ville principale (ex: Agadir / أكادير).
- [ ] seo.region : region administrative (ex: Souss-Massa).
- [ ] seo.areas et seo.areasAr : zones couvertes en respectant la parite exacte (ex: Taghazout, Aourir).
- [ ] Si CITY_HAS_AIRPORT = true : renseigner obligatoirement seo.airport, seo.airportAr, seo.airportCode, seo.meetingPoint, seo.meetingPointAr.
- [ ] Si CITY_HAS_AIRPORT = false et AIRPORT_SERVICE = true : renseigner obligatoirement la liste seo.deliveryAirports avec noms (FR/AR) et codes IATA reels (ex: CMN, RAK, AGA).

### B. Informations de Marque & Contact
- [ ] brand.name + brand.nameLight : separer le nom principal et son extension stylisee.
- [ ] website.url : URL definitive du client avec HTTPS (ex: https://nomagence.ma).
- [ ] website.contentUpdated : date du jour au format YYYY-MM-DD.
- [ ] contact.whatsapp : format international sans + (ex: 2126XXXXXXXX).
- [ ] contact.phone : format international avec + (ex: +2126XXXXXXXX).
- [ ] contact.phoneDisplay : format lisible avec espaces (doit correspondre exactement aux chiffres de phone).
- [ ] contact.address : adresse physique reelle.
- [ ] contact.geo : latitude et longitude GPS reelles (ne pas laisser a 0,0).
- [ ] contact.googleMapsLink : lien Maps HTTPS valide vers l'agence ou le point de rencontre.
- [ ] contact.sameAs : liens vers les reseaux sociaux reels du client (ou tableau vide []).

### C. Regles de Reservation & Flotte
- [ ] booking.withCaution : false pour "Sans caution", true avec caution.
- [ ] booking.advancePaymentDh : montant d'acompte en DH, ou null si aucun acompte.
- [ ] booking.freeCancellation, unlimitedKm, freeAirportDelivery, freeCityDelivery, insuranceIncluded.
- [ ] business.openingHours : format strict HH:MM-HH:MM (ex: 08:00-22:00).
- [ ] business.payments : modes de paiement acceptes (cash, transfer, card).
- [ ] fleet.cars : liste complete des vehicules, prix journaliers reels, nombre de places et type de boite/carburant.

### D. Avis Clients (reviews)
- [ ] Ajouter les avis reels du client avec langues respectives (fr, ar, en), ou laisser items: [] pour masquer le composant.

# Car Rental Template - Static White Label (Next.js 16 + Cloudflare Pages)

Template Next.js 16 ultra-performant, mobile-first et optimise pour la conversion WhatsApp directe, specialement concu pour les agences de location de voitures au Maroc.

Entierement statique (output: 'export'), il est taille pour un hebergement gratuit, securise et instantane sur Cloudflare Pages.

---

## Points Forts

- WhatsApp-First Conversion : Formulaire de reservation interactif calculant automatiquement la duree, le prix total en MAD/EUR, et generant un message WhatsApp structure.
- Support Trilingue & RTL Natif : Francais, Anglais et Arabe avec inversion de direction (dir="rtl") sans rechargement de page.
- Hebergement 100% Statique : Zero cout d'infrastructure serveur, resistant aux pics de trafic grace au CDN mondial de Cloudflare.
- Cache Optimise : En-tetes _headers preconfigures pour un cache immuable d'un an sur tous les bundles Next.js.
- Build Guard Integre : Systeme de securite interdisant le deploiement en production si des donnees demo persistent.
- SEO & Landing Pages Statiques : Generation automatique de pages dediees (/[slug]) par aeroport (si la ville en a un) ou par livraison aeroport (vers les aeroports de livraison deliveryAirports si la ville n'en a pas), ville et modalite sans caution.
- Logique Aeroport en 2 reglages : CITY_HAS_AIRPORT (la ville a son propre aeroport) et AIRPORT_SERVICE (livraison aeroport avec listing precis des aeroports desservis si la ville n'en possede pas).

---

## Stack Technique

- Framework : Next.js 16.4 (App Router, Turbopack, Static HTML Export)
- Interface : React 19.3, Tailwind CSS v4
- Typage : TypeScript 5.1+
- Traitement d'images : Sharp (compression WebP automatisee)
- Deploiement : Cloudflare Pages via Wrangler CLI

---

import sharp from 'sharp';
import { readdir, unlink } from 'fs/promises';
import { existsSync } from 'fs';

async function run() {
  const files = await readdir('./public/fleet').catch(() => []);
  for (const file of files) {
    if (!file.match(/\.(jpg|jpeg|png)$/i)) continue;
    const name = file.replace(/\.(jpg|jpeg|png)$/i, "");
    const srcPath = `./public/fleet/${file}`;
    await sharp(srcPath)
      .resize({ width: 800, withoutEnlargement: true })
      .webp({ quality: 78 })
      .toFile(`./public/fleet/${name}.webp`);
    await unlink(srcPath);
    console.log(`[Generated] fleet/${name}.webp (source ${file} supprimée)`);
  }

  if (existsSync('./public/hero.jpg')) {
    await sharp('./public/hero.jpg')
      .resize({ width: 1280, withoutEnlargement: true })
      .webp({ quality: 80 })
      .toFile('./public/hero.webp');
    console.log('[Generated] hero.webp');

    await sharp('./public/hero.jpg')
      .resize(1200, 630, { fit: 'cover' })
      .jpeg({ quality: 75, mozjpeg: true, progressive: true })
      .toFile('./public/og-hero.jpg');
    console.log('[Generated] og-hero.jpg (OpenGraph 1200x630)');

    await unlink('./public/hero.jpg');
    console.log('[Cleaned] hero.jpg supprimé');
  } else {
    console.warn('⚠️ [Avertissement] hero.jpg introuvable dans public/. Assurez-vous d\'avoir hero.webp et og-hero.jpg déjà présents.');
  }

  if (existsSync('./public/meeting-point.jpg')) {
    await sharp('./public/meeting-point.jpg')
      .resize({ width: 1280, withoutEnlargement: true })
      .webp({ quality: 78 })
      .toFile('./public/meeting-point.webp');
    await unlink('./public/meeting-point.jpg');
    console.log('[Generated] meeting-point.webp (source meeting-point.jpg supprimée)');
  } else {
    console.log('[Skipped] meeting-point.jpg not found');
  }

  console.log('DONE.');
}

run();

type Props = { params: Promise<{ slug: string }> }
const brand = `${siteConfig.brand.name} ${siteConfig.brand.nameLight}`.trim()

export async function generateMetadata({ params }: Props): Promise<Metadata> {
  const { slug } = await params
  const l = landings.find((x: Landing) => x.slug === slug)
  if (!l) return {}
  const title = `${l.title} | ${brand}`
  const canonicalUrl = `${SITE_URL}/${l.slug}`

  return { 
    title, 
    description: l.description, 
    alternates: { canonical: canonicalUrl }, 
    openGraph: { 
      title, 
      description: l.description, 
      url: canonicalUrl, 
      type: "website", 
      images: [{ url: "/og-hero.jpg", width: 1200, height: 630 }] 
    } 
  }
}

type DPProps = { value: string; onChange: (v: string) => void; placeholder: string; minDate?: string; disabledMessage?: string }

function DatePicker({ value, onChange, placeholder, minDate, disabledMessage }: DPProps) {
  const { lang, t } = useT()
  const locale = LOCALES[lang]
  const weekdays = t("calendar.weekdays").split(",")
  const [open, setOpen] = useState(false)

  const monthOf = (iso: string) => { const [y, m] = iso.split("-").map(Number); return new Date(Date.UTC(y, m - 1, 1)) }
  const base = () => (value ? monthOf(value) : minDate ? monthOf(minDate) : new Date(Date.UTC(new Date().getUTCFullYear(), new Date().getUTCMonth(), 1)))
  const [month, setMonth] = useState<Date>(base)
  const y = month.getUTCFullYear()
  const m = month.getUTCMonth()
  const offset = (new Date(Date.UTC(y, m, 1)).getUTCDay() + 6) % 7
  const count = new Date(Date.UTC(y, m + 1, 0)).getUTCDate()

  useEffect(() => {
    if (!open) return
    const prevOverflow = document.body.style.overflow
    const onKey = (e: KeyboardEvent) => { if (e.key === "Escape") setOpen(false) }
    document.addEventListener("keydown", onKey)
    document.body.style.overflow = "hidden"
    return () => {
      document.removeEventListener("keydown", onKey)
      document.body.style.overflow = prevOverflow
    }
  }, [open])

  return (
    <div className="relative">
      <button 
        type="button" 
        disabled={!!disabledMessage} 
        aria-haspopup="dialog"
        aria-expanded={open}
        onClick={() => { if (!open) setMonth(base()); setOpen(!open) }} 
        className="w-full rounded-xl border border-zinc-200 bg-white px-4 py-3 text-start text-[14px] disabled:opacity-50"
      >
        {value ? fmtDate(value, locale) : placeholder}
      </button>
      {disabledMessage && <p className="mt-1 text-[11px] text-zinc-500">{disabledMessage}</p>}
      {open && (
        <>
          <div className="fixed inset-0 z-[60] bg-black/40 backdrop-blur-sm" onClick={() => setOpen(false)} aria-hidden="true" />
          <div 
            role="dialog" 
            aria-modal="true" 
            aria-label={placeholder}
            className="fixed left-1/2 top-1/2 z-[70] w-[92vw] max-w-[340px] max-h-[90dvh] overflow-y-auto -translate-x-1/2 -translate-y-1/2 rounded-[20px] border border-zinc-200 bg-white p-5 shadow-2xl"
          >
            <div className="mb-3 flex items-center justify-between">
              <button type="button" aria-label={t("calendar.prev")} className="h-10 w-10 flex items-center justify-center rounded-full hover:bg-zinc-100" onClick={() => setMonth(new Date(Date.UTC(y, m - 1, 1)))}><span className="inline-block rtl:rotate-180">‹</span></button>
              <span className="text-[14px] font-bold capitalize" aria-live="polite">{month.toLocaleDateString(locale, { timeZone: "UTC", month: "long", year: "numeric" })}</span>
              <button type="button" aria-label={t("calendar.next")} className="h-10 w-10 flex items-center justify-center rounded-full hover:bg-zinc-100" onClick={() => setMonth(new Date(Date.UTC(y, m + 1, 1)))}><span className="inline-block rtl:rotate-180">›</span></button>
            </div>
            <div className="mb-2 grid grid-cols-7 text-center text-[10px] font-medium text-zinc-500" aria-hidden="true">{weekdays.map((d: string, i: number) => <span key={i} className="py-1">{d}</span>)}</div>
            <div className="grid grid-cols-7 gap-1">
              {Array.from({ length: offset }, (_: unknown, i: number) => <div key={`e${i}`} />)}
              {Array.from({ length: count }, (_: unknown, i: number) => {
                const dateObj = new Date(Date.UTC(y, m, i + 1));
                const iso = `${dateObj.getUTCFullYear()}-${String(dateObj.getUTCMonth() + 1).padStart(2, "0")}-${String(dateObj.getUTCDate()).padStart(2, "0")}`;
                const disabled = minDate ? iso < minDate : false
                const isSelected = value === iso
                const fullDateAria = dateObj.toLocaleDateString(locale, { timeZone: "UTC", weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' });
                
                return (
                  <button 
                    key={iso} 
                    type="button" 
                    disabled={disabled} 
                    aria-pressed={isSelected} 
                    aria-label={fullDateAria}
                    onClick={() => { onChange(iso); setOpen(false) }} 
                    className={`h-10 rounded-full text-[13px] font-medium transition ${isSelected ? "bg-zinc-900 text-white" : "hover:bg-zinc-100"} disabled:opacity-30`}
                  >
                    {i + 1}
                  </button>
                )
              })}
            </div>
            <button type="button" onClick={() => setOpen(false)} className="mt-4 w-full rounded-full bg-zinc-100 py-2.5 text-[13px] font-semibold">{t("common.close")}</button>
          </div>
        </>
      )}
    </div>
  )
}

"use client"
import { useState, useRef, useEffect } from "react"
import { LANGS, type Lang } from "@/data/translations"
import { useLang, setLang as saveLang, useT } from "@/lib/lang"

const LABELS: Record<Lang, string> = {
  fr: "FR",
  en: "EN",
  ar: "العربية",
}

export default function LangSwitcher() {
  const currentLang = useLang()
  const { t } = useT()
  const [open, setOpen] = useState(false)
  const ref = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!open) return
    const close = (e: PointerEvent) => {
      if (!ref.current?.contains(e.target as Node)) setOpen(false)
    }
    const onKey = (e: KeyboardEvent) => {
      if (e.key === "Escape") setOpen(false)
    }
    document.addEventListener("pointerdown", close)
    document.addEventListener("keydown", onKey)
    return () => {
      document.removeEventListener("pointerdown", close)
      document.removeEventListener("keydown", onKey)
    }
  }, [open])

  const changeLang = (newLang: Lang) => {
    saveLang(newLang)
    setOpen(false)
  }

  return (
    <div ref={ref} className="relative">
      <button
        type="button"
        aria-label={`${t("lang.label")} ${LABELS[currentLang]}`}
        aria-expanded={open}
        onClick={() => setOpen(!open)}
        className="flex h-9 items-center gap-1 rounded-full border border-zinc-200 bg-white px-3 text-[12px] font-bold text-zinc-700 hover:border-zinc-300"
      >
        <span>{LABELS[currentLang]}</span>
        <span className="text-[10px] opacity-60">{open ? "▲" : "▼"}</span>
      </button>

      {open && (
        <div className="absolute right-0 top-[44px] z-40 min-w-[140px] overflow-hidden rounded-2xl border border-zinc-200 bg-white shadow-xl rtl:left-0 rtl:right-auto">
          {LANGS.map((l: Lang) => (
            <button
              key={l}
              type="button"
              onClick={() => changeLang(l)}
              aria-current={currentLang === l}
              className={`flex w-full items-center justify-between px-4 py-3 text-start text-[13px] transition hover:bg-zinc-50 ${
                currentLang === l ? "bg-zinc-900 text-white hover:bg-zinc-900" : "text-zinc-700"
              }`}
            >
              <span className="font-medium">{t(`lang.${l}`)}</span>
              {currentLang === l && <span className="text-[12px]">✓</span>}
            </button>
          ))}
        </div>
      )}
    </div>
  )
}

import { createContext, useCallback, useContext, useMemo, useState, type ReactNode } from "react"
import { siteConfig, type LocationId } from "@/data/config"

import { DEFAULT_CURRENCY, type Currency } from "@/lib/currency"

export type { Currency }

interface BookingState {
  location: LocationId
  pickup: string
  ret: string
  days: number
  currency: Currency
  setLocation: (v: LocationId) => void
  setPickup: (v: string) => void
  setReturn: (v: string) => void
  setCurrency: (c: Currency) => void
}

const BookingContext = createContext<BookingState | undefined>(undefined)

export function BookingProvider({ children }: { children: ReactNode }) {
  const [location, setLocation] = useState<LocationId>(siteConfig.booking.locations[0] as LocationId)
  const [pickup, setPickupState] = useState("")
  const [ret, setRetState] = useState("")
  const [currency, setCurrency] = useState<Currency>(DEFAULT_CURRENCY)

  const setPickup = useCallback((v: string) => {
    setPickupState(v)
    setRetState((r) => (r && r < v ? "" : r))
  }, [])

  const setReturn = useCallback((v: string) => {
    if (v && pickup && v < pickup) {
      setRetState("")
      return
    }
    setRetState(v)
  }, [pickup])

  const days = useMemo(() => {
    if (!pickup || !ret || ret < pickup) return 0
    return daysBetween(pickup, ret)
  }, [pickup, ret])

  const value = useMemo(
    () => ({
      location,
      pickup,
      ret,
      days,
      currency,
      setLocation,
      setPickup,
      setReturn,
      setCurrency,
    }),
    [location, pickup, ret, days, currency, setLocation, setPickup, setReturn, setCurrency]
  )

  return <BookingContext.Provider value={value}>{children}</BookingContext.Provider>
}

export function useBooking() {
  const ctx = useContext(BookingContext)
  if (!ctx) throw new Error("useBooking must be used inside BookingProvider")
  return ctx
}

function isHttps(u: string): boolean {
  if (!/^https:\/\/\S+$/i.test(u)) return false
  try {
    const parsed = new URL(u)
    return parsed.protocol === "https:" && Boolean(parsed.hostname)
  } catch {
    return false
  }
}

function isValidISODate(s: string): boolean {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(s)) return false
  const d = new Date(`${s}T00:00:00Z`)
  return !isNaN(d.getTime()) && d.toISOString().slice(0, 10) === s
}

function isExistingFile(publicPath: string): boolean {
  if (!publicPath || !publicPath.startsWith("/") || publicPath.length < 2) return false
  const full = join(process.cwd(), "public", publicPath)
  try {
    return existsSync(full) && statSync(full).isFile()
  } catch {
    return false
  }
}

function scanPlaceholders(v: unknown, path: string, out: string[]) {
  if (typeof v === "string") {
    if (PLACEHOLDER.test(v)) out.push(`${path} (valeur de démonstration)`)
  } else if (Array.isArray(v)) {
    v.forEach((x, i) => scanPlaceholders(x, `${path}[${i}]`, out))
  } else if (v && typeof v === "object") {
    Object.entries(v).forEach(([k, x]) => scanPlaceholders(x, `${path}.${k}`, out))
  }
}

function compareShape(a: unknown, b: unknown, path: string, out: string[]) {
  if (path === "common.days") return
  if (Array.isArray(a) || Array.isArray(b)) {
    if (!Array.isArray(a) || !Array.isArray(b) || a.length !== b.length) out.push(`translations ${path} (longueur différente)`)
    else a.forEach((x, i) => compareShape(x, b[i], `${path}[${i}]`, out))
    return
  }
  if (a && b && typeof a === "object" && typeof b === "object") {
    const ra = a as Record<string, unknown>
    const rb = b as Record<string, unknown>
    new Set([...Object.keys(ra), ...Object.keys(rb)]).forEach((k) => {
      const p = path ? `${path}.${k}` : k
      if (!(k in ra) || !(k in rb)) out.push(`translations ${p} (clé absente)`)
      else compareShape(ra[k], rb[k], p, out)
    })
    return
  }
}

function scanBrokenText(v: unknown, path: string, out: string[]) {
  if (typeof v === "string") {
    if (/undefined|NaN|\[object/.test(v)) out.push(`translations ${path} (texte cassé)`)
  } else if (Array.isArray(v)) {
    v.forEach((x, i) => scanBrokenText(x, `${path}[${i}]`, out))
  } else if (v && typeof v === "object") {
    Object.entries(v).forEach(([k, x]) => scanBrokenText(x, path ? `${path}.${k}` : k, out))
  }
}

const norm = (v: string) => v.normalize("NFD").replace(/[\u0300-\u036f]/g, "").toLowerCase().replace(/\s+/g, " ").trim()

function airportClaimPatterns(city: string, cityAr: string): string[] {

function hasAirportClaim(text: string, patterns: string[]): boolean {

function collectAirportClaims(v: unknown, path: string, patterns: string[], out: string[]) {

  }
}

    publicTexts.forEach(([where, text]) => { if (hasAirportClaim(text, claims)) errors.push(`${where} : affirme que la ville a un aéroport alors que CITY_HAS_AIRPORT = false`) })
    collectAirportClaims(T, "translations", claims, errors)

    if (c.booking.airportService) {
      const list = s.deliveryAirports
      if (list.length === 0) {
        errors.push("seo.deliveryAirports est obligatoire quand CITY_HAS_AIRPORT = false et AIRPORT_SERVICE = true (ex: CMN, RAK, AGA)")
      }
      list.forEach((a, i) => {
        if (!a.name.trim() || !a.nameAr.trim() || !a.code.trim()) {
          errors.push(`seo.deliveryAirports[${i}] : name, nameAr et code sont obligatoires`)
        }
        if (a.name.trim() && norm(a.name).includes(norm(s.city))) {
          errors.push(`seo.deliveryAirports[${i}] (${a.name}) : contient le nom de la ville alors que CITY_HAS_AIRPORT = false`)
        }
        if (a.nameAr.trim() && norm(a.nameAr).includes(norm(s.cityAr))) {
          errors.push(`seo.deliveryAirports[${i}] (${a.nameAr}) : contient le nom de la ville alors que CITY_HAS_AIRPORT = false`)
        }
      })
      const codes = list.map((a) => a.code.trim().toUpperCase())
      if (new Set(codes).size !== codes.length) errors.push("seo.deliveryAirports : codes d'aéroport en double")
      if (codes.some((x) => !/^[A-Z]{3}$/.test(x))) errors.push("seo.deliveryAirports : code IATA invalide (3 lettres, ex: CMN)")
    }
  }

  if (T.fr && T.en && T.ar) {
    compareShape(T.fr, T.en, "", errors)
    compareShape(T.fr, T.ar, "", errors)
    scanBrokenText(T, "", errors)
  }

  const slugs = landings.map((l) => l.slug)
  if (slugs.length === 0 || slugs.some((x) => !x) || new Set(slugs).size !== slugs.length) {
    errors.push("landings : aucune page générée, ou slug vide / en double")
  }

  if (process.env.NEXT_PHASE === "phase-production-build") {
    const files = [
      c.hero.image,
      c.brand.logo,
      ...(c.booking.airportService ? [c.contact.meetingPointPhoto] : []),
      "/og-hero.jpg",
      ...c.fleet.cars.map((x) => x.image)
    ]
    Array.from(new Set(files)).forEach((f) => {
      if (!isExistingFile(f)) errors.push(`fichier manquant ou invalide : public${f}`)
    })
  }

  if (errors.length) {
    throw new Error(`\n🚨 [Build Guard] Build de production refusé. Erreurs:\n- ${errors.join("\n- ")}\n`)
  }
}

import { siteConfig } from "@/data/config"
import { DEFAULT_LANG } from "@/data/translations"
import { tr } from "@/lib/i18n"

export type LandingId = "airport" | "airportDelivery" | "deposit" | "nearby"
export type Landing = { id: LandingId; slug: string; title: string; description: string }

const slugify = (v: string) =>
  v.normalize("NFD").replace(/[\u0300-\u036f]/g, "").toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/^-+|-+$/g, "")

export function buildLandings(): Landing[] {
  const { city, areas } = siteConfig.seo
  const t = (k: string) => tr(DEFAULT_LANG, k)
  const nearby = areas.filter((a) => a.trim().toLowerCase() !== city.trim().toLowerCase())
  const prefix = slugify(t("seo.locationVoiture"))
  const citySlug = slugify(city)

  const all: Landing[] = []

  const { cityHasAirport, airportService, unlimitedKm } = siteConfig.booking

  if (cityHasAirport) {
    all.push({
      id: "airport",
      slug: `${prefix}-${slugify(t("seo.slugAirport"))}-${citySlug}`,
      title: t("landings.airport.metaTitle"),
      description: `${t("landings.airport.metaDescription")}${unlimitedKm ? " " + t("landings.airport.metaKm") : ""}`,
    })
  } else if (airportService) {
    all.push({
      id: "airportDelivery",
      slug: `${prefix}-${citySlug}-${slugify(t("seo.slugAirportDelivery"))}`,
      title: t("landings.airportDelivery.metaTitle"),
      description: `${t("landings.airportDelivery.metaDescription")}${unlimitedKm ? " " + t("landings.airportDelivery.metaKm") : ""}`,
    })
  }

  if (!siteConfig.booking.withCaution) {
    all.push({
      id: "deposit",
      slug: `${prefix}-${slugify(t("seo.slugDeposit"))}-${citySlug}`,
      title: t("landings.deposit.metaTitle"),
      description: t("landings.deposit.metaDescription"),
    })
  }

  // Toujours générer "nearby" s'il y a des zones voisines OU si aucune autre landing n'est active
  // (évite un tableau vide dans generateStaticParams avec output: "export").
  if (nearby.length > 0 || all.length === 0) {
    const targetSlug = slugify(nearby[0] || city)
    all.push({
      id: "nearby",
      slug: `${prefix}-${targetSlug}`,
      title: t("landings.nearby.metaTitle"),
      description: t("landings.nearby.metaDescription"),
    })
  }

  return all
}

export const landings = buildLandings()

import { siteConfig } from "@/data/config"

export type Currency = string;

export const BASE_CURRENCY: Currency = siteConfig.currency.base;
export const FOREIGN_CURRENCY: Currency = siteConfig.currency.foreign;
export const DEFAULT_CURRENCY: Currency = BASE_CURRENCY;
export const BASE_TO_FOREIGN_RATE: number = siteConfig.currency.rate;

const SYMBOLS: Record<string, string> = { EUR: "€", USD: "$", GBP: "£" }
export const FOREIGN_SYMBOL: string = SYMBOLS[FOREIGN_CURRENCY] ?? FOREIGN_CURRENCY;

export function nextCurrency(c: Currency): Currency {
  return c === BASE_CURRENCY ? FOREIGN_CURRENCY : BASE_CURRENCY;
}

export function convertPrice(priceBase: number, currency: Currency): number {
  if (currency === FOREIGN_CURRENCY) return priceBase * BASE_TO_FOREIGN_RATE;
  return priceBase;
}

export function formatPrice(priceBase: number, currency: Currency): string {
  if (currency === FOREIGN_CURRENCY) {
    const converted = convertPrice(priceBase, FOREIGN_CURRENCY);
    return `${converted.toFixed(2)} ${FOREIGN_SYMBOL}`;
  }
  return `${priceBase} ${BASE_CURRENCY}`;
}

export function formatPriceDual(priceBase: number): { base: string; foreign: string } {
  return {
    base: formatPrice(priceBase, BASE_CURRENCY),
    foreign: `~${formatPrice(priceBase, FOREIGN_CURRENCY)}`,
  }
}

export function formatTotal(priceBase: number, days: number, currency: Currency): string {
  return formatPrice(priceBase * days, currency);
}

const pad = (n: number) => String(n).padStart(2, "0")

export function toISO(d: Date): string {
  return `${d.getUTCFullYear()}-${pad(d.getUTCMonth() + 1)}-${pad(d.getUTCDate())}`
}

export function todayInZone(timeZone: string): string {
  try {
    const parts = new Intl.DateTimeFormat("en-US", { timeZone, year: "numeric", month: "2-digit", day: "2-digit" }).formatToParts(new Date())
    const get = (type: string) => parts.find((p) => p.type === type)?.value
    const y = get("year"), m = get("month"), d = get("day")
    if (y && m && d) return `${y}-${m}-${d}`
  } catch (e) {
    console.warn("Timezone fallback:", e)
  }
  return toISO(new Date())
}

export function fromISO(s: string): Date {
  const [y, m, d] = s.split("-").map(Number)
  return new Date(Date.UTC(y, m - 1, d, 0, 0, 0))
}

export function fmtDate(d: string | Date, locale: string): string {
  const date = typeof d === "string" ? fromISO(d) : d
  if (isNaN(date.getTime())) return ""
  return date.toLocaleDateString(locale, { timeZone: "UTC", day: "2-digit", month: "short", year: "numeric" })
}

export function daysBetween(a: string, b: string): number {
  const dateA = fromISO(a).getTime()
  const dateB = fromISO(b).getTime()
  if (isNaN(dateA) || isNaN(dateB)) return 0
  const diff = dateB - dateA
  return Math.max(1, Math.round(diff / 86400000))
}

export function addDaysISO(value: string, days: number): string {
  const date = fromISO(value)
  date.setUTCDate(date.getUTCDate() + days)
  return toISO(date)
}

import { DEFAULT_LANG, translations, type Lang } from "@/data/translations"

export type Vars = Record<string, string | number>

export const LOCALES: Record<Lang, string> = { fr: "fr-FR", en: "en-GB", ar: "ar-MA" }

function lookup(dict: unknown, path: string): unknown {
  return path.split(".").reduce<unknown>((o, k) => {
    if (o && typeof o === "object") return (o as Record<string, unknown>)[k]
    return undefined
  }, dict)
}

function fill(s: string, vars?: Vars): string {
  if (!vars) return s
  return s.replace(/\{(\w+)\}/g, (_, n: string) => (n in vars ? String(vars[n]) : `{${n}}`))
}

export function tr(lang: Lang, path: string, vars?: Vars): string {
  let v = lookup(translations[lang], path)
  if (typeof v !== "string") v = lookup(translations[DEFAULT_LANG], path)
  if (typeof v !== "string") {
    if (typeof window === "undefined" && process.env.NODE_ENV !== "production") {
      console.warn(`i18n: missing key "${path}"`)
    }
    return path
  }
  return fill(v, vars)
}

function pluralCategory(lang: Lang, n: number): "one" | "two" | "few" | "other" {
  if (n === 1) return "one"
  if (lang === "ar") {
    if (n === 2) return "two"
    if (n >= 3 && n <= 10) return "few"
  }
  return "other"
}

export function trn(lang: Lang, path: string, n: number): string {
  let forms = lookup(translations[lang], path)
  if (!forms || typeof forms !== "object") forms = lookup(translations[DEFAULT_LANG], path)
  if (!forms || typeof forms !== "object") return path
  const f = forms as Record<string, string>
  return fill(f[pluralCategory(lang, n)] ?? f.other ?? path, { n })
}

"use client"
import { useSyncExternalStore } from "react"
import { DEFAULT_LANG, type Lang } from "@/data/translations"
import { tr, trn } from "./i18n"

let currentLang: Lang = DEFAULT_LANG
const listeners = new Set<() => void>()

function subscribe(listener: () => void) {
  listeners.add(listener)
  return () => listeners.delete(listener)
}

function getSnapshot(): Lang {
  return currentLang
}

function getServerSnapshot(): Lang {
  return DEFAULT_LANG
}

if (typeof window !== "undefined") {
  let stored: Lang | null = null
  try {
    stored = localStorage.getItem("lang") as Lang
  } catch {}

  if (stored === "fr" || stored === "en" || stored === "ar") {
    currentLang = stored
  } else {
    const nav = (navigator.language || "").slice(0, 2)
    currentLang = nav === "ar" ? "ar" : nav === "fr" ? "fr" : "en"
  }
  document.documentElement.lang = currentLang
  document.documentElement.dir = currentLang === "ar" ? "rtl" : "ltr"

  window.addEventListener("storage", (e) => {
    if (e.key === "lang" && e.newValue) {
      const l = e.newValue as Lang
      if (l === "fr" || l === "en" || l === "ar") {
        currentLang = l
        document.documentElement.lang = l
        document.documentElement.dir = l === "ar" ? "rtl" : "ltr"
        listeners.forEach((fn) => fn())
      }
    }
  })
}

export function setLang(lang: Lang) {
  currentLang = lang
  if (typeof window !== "undefined") {
    document.documentElement.lang = lang
    document.documentElement.dir = lang === "ar" ? "rtl" : "ltr"
    try {
      localStorage.setItem("lang", lang)
    } catch {}
  }
  listeners.forEach((fn) => fn())
}

export function useLang(): Lang {
  return useSyncExternalStore(subscribe, getSnapshot, getServerSnapshot)
}

export function useT() {
  const lang = useLang()
  return {
    lang,
    t: (path: string, vars?: Record<string, string | number>) => tr(lang, path, vars),
    tn: (path: string, n: number) => trn(lang, path, n)
  }
}

import { BRAND, siteConfig } from "@/data/config"
import { type Lang, DEFAULT_LANG } from "@/data/translations"
import { tr } from "@/lib/i18n"
import { BASE_CURRENCY, formatPrice } from "@/lib/currency"

type WhatsAppData = {
  car?: string
  pickupDate?: string
  returnDate?: string
  location?: string
  days?: string
  pricePerDay?: number
  total?: number
  ref?: string
}

function getT(lang: string) {
  const l = (["fr", "en", "ar"].includes(lang) ? lang : DEFAULT_LANG) as Lang
  return (k: string, vars?: Record<string, string | number>) => tr(l, k, vars)
}

export function getWhatsAppMessage(lang: string, data: WhatsAppData): string {
  const t = getT(lang)
  const lines: string[] = []

  lines.push(t("wa.hello", { brand: BRAND }))
  lines.push("")
  if (data.car) lines.push(t("wa.car", { car: data.car }))

  if (data.pickupDate && data.returnDate) {
    lines.push(t("wa.dates", { from: data.pickupDate, to: data.returnDate }))
  } else if (data.pickupDate) {
    lines.push(t("wa.date", { date: data.pickupDate }))
  } else if (data.returnDate) {
    lines.push(t("wa.date", { date: data.returnDate }))
  }

  if (data.location) lines.push(t("wa.place", { place: data.location }))
  if (data.days) lines.push(t("wa.duration", { duration: data.days }))
  if (data.pricePerDay) lines.push(t("wa.price", { price: formatPrice(data.pricePerDay, BASE_CURRENCY) }))
  if (data.total && data.days) lines.push(t("wa.total", { total: formatPrice(data.total, BASE_CURRENCY) }))

  lines.push("")
  lines.push(t("wa.ask"))
  lines.push(t("wa.thanks"))
  if (data.ref) {
    lines.push("")
    lines.push(`_Ref: ${data.ref}_`)
  }
  return lines.join("\n")
}

export function getWhatsAppLink(lang: string, data: WhatsAppData): string {
  const message = getWhatsAppMessage(lang, data)
  const phone = siteConfig.contact.whatsapp.replace(/\D/g, "")
  const safeMessage = Array.from(message).slice(0, 1500).join("")

  return `https://wa.me/${phone}?text=${encodeURIComponent(safeMessage)}`
}
